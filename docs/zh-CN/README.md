版本说明：当前发布版本是 `0.2.0`。CaPS、balanced/EPR FM-index、FM batch、
Sapling PWL 和采样 SA 已经发布，其中 Sapling PWL 与采样 SA 仍为默认关闭的
实验性能力。详细历史测量只保留在源码归档中，不进入普通用户文档路径。
